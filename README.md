# Одностраничный сайт для кредитного брокера

Одностраничный презентационный сайт для компании, оказывающей услуги в сфере кредитования бизнеса.

Сайт содержит презентационный блок с рекламными видеороликами и форму обратной связи для отправки заявок на электронную почту.

## 🚀 Технологии

### Frontend

* React
* React Bootstrap
* Styled Components
* JavaScript / JSX
* HTML5 Video
* CSS

### Backend

* Node.js
* Nodemailer
* CORS
* SMTP Mail.ru

## ✨ Основные возможности

* Адаптивная верстка для desktop и мобильных устройств
* Использование сетки React Bootstrap
* Презентация рекламных видеороликов
* Кастомная типографика
* Стилизация компонентов с помощью Styled Components
* Форма обратной связи
* Отправка заявок на электронную почту
* Отправка писем через SMTP

## 📌 Назначение проекта

Проект разработан как одностраничный сайт-презентация для бизнеса с возможностью получения заявок от потенциальных клиентов через форму обратной связи.
